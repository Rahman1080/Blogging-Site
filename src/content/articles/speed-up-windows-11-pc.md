A slow Windows 11 PC doesn't mean it's time to buy a new one. Most slowdowns come from a handful of correctable problems: too many startup programs, nearly-full disk, bloated background processes, or outdated drivers.

These fixes are ordered from fastest to most involved. Try them in order and test after each one — you'll usually notice a difference well before the end.

## 1. Restart your PC

Windows is famous for needing a restart now and then. If it's been days or weeks since you rebooted, start there — it clears accumulated background processes and memory.

1. Click **Start → Power → Restart** (not Shut down, which on some systems uses fast startup and keeps things loaded).
2. Log back in and check performance.

## 2. Disable unnecessary startup programs

Too many apps launching at boot is one of the most common causes of a slow, sluggish startup.

1. Press **Ctrl+Shift+Esc** to open Task Manager.
2. Go to the **Startup apps** tab.
3. Look at the **Startup impact** column.
4. Right-click anything you don't need at login (chat apps, updaters, media apps) and choose **Disable**.

Only keep what you genuinely use every session. You'll still be able to open these apps normally later.

## 3. Free up disk space

Windows needs breathing room to run smoothly, especially for virtual memory and updates.

1. Open **Settings → System → Storage**.
2. Click **Cleanup recommendations** and review **Temporary files**, **Unused apps**, and **Large files**.
3. Let **Storage Sense** clean automatically: turn it on and set it to run when space runs low.
4. Aim to keep at least 15–20% of your main drive free.

## 4. Update Windows and drivers

Updates fix bugs and improve performance, but only if they're installed.

- **Settings → Windows Update → Check for updates**, then install and restart.
- For hardware drivers, use **Settings → Windows Update → Advanced options → Optional updates** for driver updates, or check your manufacturer's support site (especially for graphics drivers).

## 5. Check what's eating your RAM and CPU

Task Manager will tell you if something specific is misbehaving.

1. Open Task Manager (**Ctrl+Shift+Esc**) → **Processes**.
2. Sort by **Memory** and **CPU** (click the column headers).
3. For any app using far more than expected, right-click → **End task**. If it's a system process, restart instead of ending it.
4. If memory regularly sits at 90%+, see the RAM question below.

## 6. Disable visual effects (if you're really struggling)

On older hardware, animations and transparency cost noticeable performance.

1. Press **Win+R**, type `sysdm.cpl`, and press Enter.
2. Go to **Advanced → Performance → Settings**.
3. Choose **Adjust for best performance** (or disable just the animations you don't need).

## 7. Run a quick malware check

Background malware and adware quietly consume CPU and memory.

- Use **Windows Security → Virus & threat protection → Scan options → Full scan**.
- Be suspicious of unfamiliar programs in **Settings → Apps**.

## 8. Upgrade from hard drive to SSD

If your PC still uses a traditional spinning hard drive (HDD), this single upgrade makes a bigger difference than everything else in this guide combined. Boot times drop from minutes to seconds, and apps feel instant. SSDs are inexpensive and most laptops/desktops can accept one — check your model's manual.

## 9. Add more RAM

If Task Manager regularly shows memory above 90%, extra RAM is the right fix. 16 GB handles modern browsers, Office, and multitasking comfortably. Many laptops have removable RAM; some ultrabooks are soldered, so check before buying.

## 10. Reset or clean-install Windows (last resort)

If nothing else helps, a fresh start often clears years of accumulated junk.

- **Settings → System → Recovery → Reset this PC → Remove everything** (back up your files first, using OneDrive or an external drive).
- Reinstall only the apps you actually use.

## When it's time for a new PC

If your machine is 6+ years old, can't be upgraded to 16 GB of RAM or an SSD, or keeps failing despite these fixes, a replacement will serve you better. Read our [how to choose a laptop buying guide](/articles/how-to-choose-a-laptop-buying-guide) before you shop — the money spent on the right specs now saves you from slow performance later.

## Wrapping up

Restart → clean startup apps → free up disk → update. For most people those four steps eliminate 80% of everyday sluggishness. SSD and RAM upgrades are the hardware fixes that truly transform an older PC.
